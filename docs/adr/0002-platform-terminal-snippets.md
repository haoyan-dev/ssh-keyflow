# ADR 0002: コピペ対象を端末で実行できるスクリプトにする

- 状態: 採用
- 日付: 2026-11-09
- 仕様: `.scratch/platform-copy-paste-snippets/spec.md`

## 背景

利用者が求めるコピペ操作は、説明文や設定ファイルの断片のコピーではなく、
対応する端末へ貼り付けて実行できるスクリプトである。
従来のガイド全体をコピーすると、接続先とローカルの作業が混在していた。

## 決定

ガイドを接続先での公開鍵配置、ローカルでのSSH config追記、接続コマンドの
独立したステップにする。接続先の保存済みOSとWindowsアカウント種別を使い、
ローカルのスクリプトは実行中のアプリのOSを使う。
Linux/macOSはPOSIXシェル、WindowsはPowerShellとする。
TUIではステップを切り替え、表示中の実行用スクリプトだけをコピーする。
CLIではすべてのステップと貼り付け先を明示する。

ADR 0001のサーバー設定用スクリプト除外を、公開鍵ファイルとクライアントの
SSH configへの追記について更新する。利用者が明示的に貼り付けて実行する
スクリプトの生成を認める。SSHサーバーの導入・起動・ファイアウォール変更は
引き続き扱わない。アプリ自身はスクリプトやSSH接続を実行しない。

既存の鍵と設定を保持し、公開鍵の再配置で重複を追加しない。
ローカルconfigの同じ明示的な別名があれば追記を止める。
Include、ワイルドカード、Match、優先順位の確認は利用者が行う。
Windowsでは標準アカウントの本人確認と管理者用端末の昇格確認を区別し、
共有の管理者鍵ファイル以外のサーバー設定を変更しない。

公開鍵のみ・展開を避けられない秘密鍵パスでは配置ステップだけを残す。
表示・コピーは読み取り専用であり、関連付けや登録・接続成功を記録しない。
状態スキーマと既存の配布契約は変えない。
