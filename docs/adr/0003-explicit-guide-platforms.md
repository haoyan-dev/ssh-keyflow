# ADR 0003: ガイドのローカル・接続先OSを明示する

- 状態: 採用
- 日付: 2026-11-09
- 仕様: `.scratch/guide-platform-selection/spec.md`

## 背景

Windows版のアプリからWSLの端末に貼り付ける場合など、アプリ実行元のOSと
スクリプトを実行する端末のOSは一致しない。ADR 0002の実行元OSだけに従う
ローカルスクリプトでは、利用者が対応する端末を選べない。

## 決定

ADR 0002のOS選択を更新する。ガイド作成時にローカルと接続先それぞれの
linux / macos / windowsを明示する。既定は実行元OSと保存済み接続先OSとし、
TUIのガイドフォームで確認・変更できる。CLIも同じガイド専用の選択肢を提供する。
Windows接続先ではstandard / administratorも確認する。
選択はガイドだけに適用し、保存済みの接続先・鍵・関連付けを変更しない。

ローカルOSを変える場合、管理済み鍵ペアにはその端末から見た秘密鍵パスを
必須とする。指定OSの絶対パスまたは ~/pathを受け付け、ドライブ対応を
推測せず、鍵をコピーしない。そのパスが指紋に対応する鍵を指すかは利用者が
確認する。管理済み元ファイルの検証は引き続き行う。公開鍵のみの取り込みは
パス指定があっても公開鍵配置ステップだけとする。

スクリプトの言語はLinux/macOSでPOSIXシェル、WindowsでPowerShell。
接続ステップも選択したローカルOSを明示する。スクリプトだけのコピー、
表示の読み取り専用性、成功未確認の扱い、配布契約は維持する。
