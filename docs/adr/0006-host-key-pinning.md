# ADR 0006: 接続先のホスト公開鍵をアプリ所有のknown_hostsに固定する

- 状態: 採用
- 日付: 2026-11-12
- 仕様: `.scratch/host-key-pinning/spec.md`
- 検証: `.scratch/host-key-pinning/openssh-spike.md`

## 背景

公開鍵の配置はADR 0002のスクリプトで行えるが、最初の接続ではホスト鍵の
確認（TOFU）が残る。利用者は接続先の端末にコンソール等で入れるため、
ホスト公開鍵をその場で読み、信頼できる経路で手元へ運べる。

接続先側にもアプリを入れて鍵を交換する案も検討した。しかし鍵の配置は既存
スクリプトと重複し、Windowsの権限設定を二重に実装することになる。
新しい価値はホスト鍵の取得だけで、その方向は接続先から手元への一方向である。

## 決定

ガイドに読み取り専用の「ホスト鍵の表示」ステップ（接続先）と
「ホスト鍵の固定」ステップ（ローカル）を加える。利用者は接続先で
`/etc/ssh/ssh_host_*_key.pub` または `%ProgramData%\ssh\ssh_host_*_key.pub`
を表示し、出力を `hosts pin` に貼り付ける。Windowsではホスト鍵を
標準ユーザーが読めないため、管理者として開いたPowerShellで表示する。
TUIの `t` / `T` も同じ処理をネイティブ端末への引き渡しで実行する。
アプリは厳格に解析し、指紋を表示して確認を得てから
`~/.ssh/ssh-keyflow/known_hosts` に `ssh-keyflow-<host-id>` 名で書き込む。
既存の固定と異なる鍵への置き換えには、新旧の指紋を表示したうえで
`--replace` と実端末での `yes` 入力を必要とし、`--yes` では置き換えない。
`hosts unpin` は実端末での確認後に固定を解除する。

固定済みの接続先のHostスニペットには `HostKeyAlias ssh-keyflow-<host-id>`、
アプリのファイルだけを指す絶対パスの `UserKnownHostsFile`、
`StrictHostKeyChecking yes` を加える。未固定の接続先のスニペットは変えない。
固定の有無はガイド生成時にファイルから判断し、未固定の間は表示・固定の
2ステップを示す。固定後にガイドを再生成すると、これらの行が加わる。
ファイルパスと `hosts pin` はアプリ実行中の端末のものであるため、
ガイドのローカルOSが実行元と異なる場合は固定に関する行もステップも出さない。

ADR 0001が設定ファイルの所有を外した判断を、`~/.ssh/ssh-keyflow/` 配下の
このファイルについてだけ更新する。`~/.ssh/known_hosts`、SSH config、
`sshd_config` は引き続き編集しない。アプリはネットワーク接続を開かず、
`ssh` もスクリプトも実行しない。接続先には何も導入しない。

公開鍵のみの鍵にも、保存済みの公開鍵パスを `IdentityFile` とし
`IdentitiesOnly yes` を付けたスニペットと接続コマンドを生成する。
秘密鍵はSSHエージェント（FIDO鍵等）が提供する。

## 互換性とデータ保全

状態スキーマは変えない。固定の有無はファイルからだけ判断し、旧版は
このファイルを無視するため、ダウングレードに影響しない。書き込みは
`state.json` と同じ排他ロック・原子的保存・シンボリックリンク拒否・
権限検査を使い、他の接続先の行を保持する。不正なファイルは自動修復せず、
固定・解除を止める。

接続先の管理削除は固定を消さず、アクセスの失効も意味しない。削除IDは
再利用しないため、残った行は他の接続先に影響しない。固定は接続成功を
意味せず、配置や接続の状態は引き続き記録しない。

## 影響

新しいコマンド、ガイドステップ、`hosts list --json` の `host_key_pins` 項目、
固定済みと公開鍵のみのスニペットの出力が変わるため、v0.10.0へMINORを更新する。
利用者は初回接続でホスト鍵を確認する必要がなくなる。ホスト鍵を更新した
接続先では接続が拒否されるため、再固定が必要になる。

実装前にLinux（OpenSSH 9.6p1・9.2p1）とWindows（Win32-OpenSSH 9.5p2、
Git for Windows 10.2p1）で次を確かめた。`HostKeyAlias` はホスト名とポートの
両方を置き換えて照合するため、ポートを変えても固定は有効である。
Win32-OpenSSHは引用符付きの絶対パスを受け付ける。公開鍵ファイルを
`IdentityFile` にすると、エージェント内の対応する鍵だけを使う。
Windowsのホスト公開鍵は標準ユーザーでは読めない。macOSは未検証であり、
`docs/verification.md` に制限として記録する。
