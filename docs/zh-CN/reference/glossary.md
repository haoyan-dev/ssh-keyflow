# 术语表（概要）

简体中文 · [English](../../en/reference/glossary.md) · [日本語](../../../GLOSSARY.md)

> 本页是中文概要。具有约束力的术语定义是日语版的[术语表](../../../GLOSSARY.md)，两者如有出入，以日语版为准。

[文档索引](../README.md) · [应用契约（概要）](application-contract.md)

SSH KeyFlow 是一款 CLI，用于管理本机的 SSH 密钥对，并以可复制的形式显示公钥。中文文档统一使用下表中的术语。

| 中文术语 | 正本术语 | 含义 | 避免使用 |
| --- | --- | --- | --- |
| 受管密钥 | 管理対象の鍵（Key） | 由工具创建或由用户明确导入的本机密钥对。保存固定 ID、指纹、公钥和私钥的路径、私钥摘要以及创建或导入的来源。不保存私钥内容。 | 仅有公钥的密钥（v0.11.0 已废弃） |
| 导入 | 取り込み（Import） | 验证现有的公钥与私钥组合，不移动文件即将其纳入管理的操作。不提供仅导入公钥的功能。 | — |
| 本地密钥创建 | ローカル鍵作成（Creation） | 使用原生 ssh-keygen 创建密钥，以及中断时以相同 ID 和路径恢复所需的已保存进度。是 `resume` 唯一处理的操作，完成后从状态中去除。 | — |
| 从管理中移除 | 管理からの削除（Removal） | 将密钥从受管列表中去掉的操作。不更改密钥文件、SSH 设置或已部署到其他机器上的公钥，不会吊销 SSH 访问。 | ローカル鍵の削除（删除本地密钥） |
| 删除本地密钥 | ローカル鍵の削除 | 从运行应用的机器上删除公钥和私钥文件。不包含在当前功能中。 | 管理からの削除（从管理中移除） |
| 手动部署公钥 | 手動の公開鍵配置 | 用户将 `keys public` 的输出追加到连接目标的 `authorized_keys` 等文件中。应用不执行也不验证。 | — |
| 上一状态备份 | 直前状態のバックアップ | 保存状态时的 `state.json.bak`，以滚动更新方式保存上一个有效状态的字节内容。 | — |
| 迁移归档 | 移行アーカイブ（Migration archive） | 在首次保存前将 v1 / v2 的 `state.json` 写出得到的 `state.v<N>-<UTC时间>.json`。不覆盖、不自动删除，保留包括未沿用到 v3 的连接目标和历史在内的原始字节内容。降级时手动恢复。 | 备份（与 `state.json.bak` 区分） |
