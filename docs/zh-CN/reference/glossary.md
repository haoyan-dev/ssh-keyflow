# 术语表（概要）

简体中文 · [English](../../en/reference/glossary.md) · [日本語](../../../GLOSSARY.md)

> 本页是中文概要。具有约束力的术语定义是日语版的[术语表](../../../GLOSSARY.md)，两者如有出入，以日语版为准。

[文档索引](../README.md) · [应用契约（概要）](application-contract.md)

SSH KeyFlow 是一款 CLI，用于管理本机的 SSH 密钥对，并以可复制的形式显示公钥。中文文档统一使用下表中的术语。

| 中文术语 | 正本术语 | 含义 | 避免使用 |
| --- | --- | --- | --- |
| 受管密钥 | 管理対象の鍵（Key） | 由工具创建或由用户明确导入的本机密钥对。保存固定 ID、指纹、公钥和私钥的路径、私钥摘要以及创建或导入的来源。不保存私钥内容。 | 仅有公钥的密钥（v0.11.0 已废弃） |
| 导入 | 取り込み（Import） | 验证现有的公钥与私钥组合，不移动文件即将其纳入管理的操作。不提供仅导入公钥的功能。 | — |
| 本地密钥创建 | ローカル鍵作成（Creation） | 使用原生 ssh-keygen 创建密钥，以及中断时以相同 ID 和路径恢复所需的已保存进度。是 `resume` 唯一处理的操作，完成后从状态中去除。 | — |
| 从管理中移除 | 管理からの削除（Removal） | 将密钥从受管列表中去掉的操作。不更改密钥文件、SSH 设置或已部署到其他机器上的公钥，不会吊销 SSH 访问。 | ローカル鍵の削除（删除本地密钥） |
| 删除本地密钥 | ローカル鍵の削除 | 从运行应用的机器上删除公钥和私钥文件。不包含在当前功能中。 | 管理からの削除（从管理中移除） |
| 手动部署公钥 | 手動の公開鍵配置 | 用户将 `keys public` 的输出追加到连接目标的 `authorized_keys` 等文件中。应用不执行也不验证。 | — |
| 上一状态备份 | 直前状態のバックアップ | 保存状态时的 `state.json.bak`，以滚动更新方式保存上一个有效状态的字节内容。 | — |
| 迁移归档 | 移行アーカイブ（Migration archive） | 在首次保存前将旧版架构（v1 至 v3）的 `state.json` 写出得到的 `state.v<N>-<UTC时间>.json`。不覆盖、不自动删除，保留包括 v1 / v2 中未沿用到 v3 的连接目标和历史在内的原始字节内容。降级时手动恢复。 | 备份（与 `state.json.bak` 区分） |

## 计划中的术语（ADR 0008，尚未发布）

以下术语来自 [ADR 0008](../../adr/0008-signed-fleet-roster.md)（日语，已采纳），尚不属于任何已发布的功能。

| 中文术语 | 正本术语 | 含义 | 避免使用 |
| --- | --- | --- | --- |
| 机群 | フリート（Fleet） | 以同一机群根密钥作为信任起点固定下来的用户节点集合。 | — |
| 节点 | ノード（Node） | 加入机群的机器。角色为连接源、连接目标之一或两者兼有。 | — |
| 管理节点 | 管理ノード（Admin node） | 持有机群根密钥并为名册签名的节点。 | — |
| 连接源 | 接続元（Client） | 发起 SSH 连接一方的角色。受管密钥（创建或导入均可）的公钥列入名册。 | 主机（OpenSSH 的 `Host`、主机密钥和 `known_hosts` 指的是连接目标） |
| 连接目标 | 接続先（Remote） | 通过 sshd 接受连接一方的角色。其现有主机公钥列入名册，并通过 `authorized_keys` 中的受管块接受连接源的公钥。 | 与 v0.11.0 已废弃的连接目标记录混淆 |
| 机群根密钥 | フリートルート鍵（Fleet root key） | 管理节点上用于为名册签名、受密码短语保护的密钥。每个节点只将此公钥及已登记的备用根公钥固定为信任起点。 | — |
| 固定 | 固定（Pin） | 在用户确认指纹后，将作为信任起点的机群根公钥和机群 ID 保存到状态中。首次接受名册时固定，此后只接受由已固定密钥签名的名册。 | — |
| 节点描述 | ノード記述（Node description） | 由 `node set` 保存到状态中的本机作为节点的名称、角色、密钥和连接目标信息。 | — |
| 节点描述文件 | ノード記述ファイル（Node description file） | 为将节点描述交给管理节点而写出的未签名 `node.json`。管理节点先与 `node show` 显示的指纹核对，再将其加入名册。 | — |
| 名册 | 名簿（Roster） | 带版本号、由机群根密钥签名的文档，列出各节点及其公钥、主机公钥、角色和登录账户。 | — |
| 受管块 | 管理ブロック（Managed block） | `authorized_keys` 中由工具所有的带分隔标记的范围。不更改块外的行。 | — |
| 中继服务器 | 中継サーバー（Relay） | 在节点之间传递已签名名册和加入时口令交换的不受信任服务器。它能阻止更新，但不能伪造密钥。 | — |
