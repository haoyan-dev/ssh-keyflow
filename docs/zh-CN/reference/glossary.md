# 术语表（概要）

简体中文 · [English](../../en/reference/glossary.md) · [日本語](../../../GLOSSARY.md)

> 本页是中文概要。具有约束力的术语定义是日语版的[术语表](../../../GLOSSARY.md)，两者如有出入，以日语版为准。

[文档索引](../README.md) · [应用契约（概要）](application-contract.md)

SSH KeyFlow 管理本地的 SSH 密钥和连接目标，并通过复制粘贴辅助部署公钥和设置连接。中文文档统一使用下表中的术语。

| 中文术语 | 正本术语 | 含义 | 避免使用 |
| --- | --- | --- | --- |
| 连接目标 | 接続先（Destination） | 进行 SSH 连接的机器与登录用户、端口、操作系统的组合；在保存数据和 CLI 中表示为 Host / `hosts`。不代表已注册或可以连接。 | — |
| 别名 | 別名 | 用于指定连接目标的名称。不会自动反映到 SSH 设置中，粘贴前由用户确认是否与现有 Host 重复。 | — |
| 受管密钥 | 管理対象の鍵（Key） | 由工具创建或由用户明确导入的密钥，也包括仅有公钥的密钥。保存固定 ID、指纹、文件路径以及创建或导入的来源。 | — |
| 关联 | 関連付け（Association） | 在本地保存的密钥与连接目标组合的元数据，保存在 v2 的 `associations` 中。独立于注册历史和连接成功，不会从旧注册历史自动转换。 | — |
| 从管理中移除 | 管理からの削除（Removal） | 将密钥或连接目标从受管列表中去掉并解除其全部关联的操作。已移除的元数据保存在 `removed_keys` / `removed_hosts` 中，以保持创建结果和旧历史的引用；不更改密钥文件、SSH 设置或连接目标上的公钥注册。 | — |
| 解除关联 | 関連付けの解除（Dissociation） | 只从 `associations` 中去掉指定的密钥与连接目标组合的操作。密钥和连接目标仍受管理，SSH 访问不会被吊销。 | — |
| 手动设置指南 | 手動設定ガイド（Guide） | 按所选连接目标的操作系统和账户给出公钥部署脚本和手动取消注册说明。如果有私钥或仅有公钥的密钥（使用代理），还包含面向所选本地操作系统的 SSH config 追加脚本和独立的 `ssh 別名` 连接步骤。未固定的连接目标包含显示和固定主机密钥的步骤，已固定的则在 SSH config 中包含用于固定的行。带口令或无法判断是否带口令的密钥，还包含 `AddKeysToAgent yes` 和 ssh-agent 自动启动步骤。默认使用运行应用的操作系统以及已保存的连接目标操作系统和账户，可以只为指南更改；本地操作系统不同时，需指定从该终端看到的私钥路径。每个步骤标明粘贴的终端，TUI 只复制所选步骤的可运行脚本。显示和复制不会更改设置、运行或记录成功；只有用户在终端中运行脚本时才会更改文件。 | — |
| 主机密钥固定 | ホスト鍵の固定（Host key pinning） | 将在连接目标自身终端中显示的主机公钥按连接目标 ID 保存到固定文件。已固定连接目标的 Host 片段只引用固定文件，省去首次连接确认并拒绝其他密钥；不代表连接成功或公钥已部署，替换为不同密钥需要明确指定并确认。 | ホスト鍵の登録（登记主机密钥）、known_hostsへの追加（添加到 known_hosts） |
| 固定文件 | 固定ファイル（Pin file） | 应用所有的 `~/.ssh/ssh-keyflow/known_hosts`，只包含以 `ssh-keyflow-<host-id>` 命名的行。与用户的 `~/.ssh/known_hosts` 分开，无效内容不会被自动修复。 | — |
| 未验证 | 未確認（Unverified） | 应用尚未验证当前注册或连接是否成功的状态。新的密钥、关联和指南都按此前提处理，不提供记录手动成功的操作。 | — |
| 本地密钥创建 | ローカル鍵作成（Creation） | 使用原生 ssh-keygen 创建密钥，以及中断时以相同 ID 和路径恢复所需的已保存进度。是当前 `resume` 唯一处理的操作。 | — |
| 旧注册历史 | 旧登録履歴 | 以前版本保存的注册、取消注册、连接确认和进度记录。保留固定 ID 和值的只读历史信息，不保证当前的注册或连接状态。 | — |
| 手动取消注册 | 手動の登録解除 | 用户从连接目标的密钥文件中删除指定公钥所在的行。应用不执行也不验证。 | ローカル鍵の削除（删除本地密钥） |
| 删除本地密钥 | ローカル鍵の削除 | 从运行应用的机器上删除公钥和私钥文件。不包含在当前功能中；旧删除进行到一半的记录会保留，只有目标密钥因需要手动确认而不可用。 | 登録解除（取消注册） |
| 上一状态备份 | 直前状態のバックアップ | 保存状态时的 `state.json.bak`，以滚动更新方式保存上一个有效状态的字节内容；不是永久保存 v1 的迁移用归档。 | — |
