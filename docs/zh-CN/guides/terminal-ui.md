## 启动与按键操作

在终端中不带参数运行，或运行 `ssh-keyflow tui`，即可打开 TUI。在 Keys（密钥）和 Destinations（连接目标）中，可以创建和导入密钥、将密钥关联到连接目标，以及显示和复制公钥与手动设置指南。连接目标需要选择已创建或已导入的密钥。如需新密钥，请先单独创建密钥。操作按键请参阅界面内的帮助。

| 按键 | 操作 |
| --- | --- |
| Tab / Shift+Tab | 切换 Keys / Destinations |
| ↑ / ↓、Enter | 选择、显示详情 |
| `/` / `x` | 搜索 / 清除搜索 |
| `c` / `i` | 在 Keys 中创建 / 导入密钥 |
| `a` / `l` | 添加连接目标 / 关联密钥与连接目标 |
| `d` / `u` | 将所选密钥或连接目标从管理中移除 / 解除现有关联 |
| `p` / `g` | 显示公钥 / 部署、移除和连接指南 |
| `t` / `T` | 固定 / 解除所选连接目标的主机密钥 |
| `y` | 复制公钥，或指南中当前所选步骤的可运行脚本 |
| ← / →、`b` / `n` | 指南的上一步 / 下一步 |
| `s` | 恢复所选的未完成本地密钥创建 |
| `v` / F5 | 只读的技术详情和旧历史 / 重新加载保存的状态 |
| `?` / Esc / `q` | 帮助 / 返回 / 退出 |

复制功能需要终端支持 OSC52。如果无法使用，请将 CLI 中 `keys public --key ID` / `hosts guide --host ID --key ID` 的输出导入编辑器或操作系统的剪贴板。公钥请保持为一行，不要把 TUI 显示中的自动折行当作换行粘贴。较长的正文可以用方向键、PgUp / PgDn、Home / End 翻阅。最小终端尺寸为 32 列 × 12 行。在表单中用 Tab / Shift+Tab 移动，用 Ctrl+S 继续，用 Esc / Ctrl+C 取消输入。

TUI 用边框分隔导航、列表与正文、搜索与表单输入、消息以及菜单。列表项之间留有空行，并用颜色或符号标示所选的项目或输入框，以及注意事项和输入错误。表单的 Continue / Cancel / Help 固定在底部菜单中。在较小的终端中会减少显示条数，并在没有通知时省略消息框。如果不想使用颜色，请在启动前设置环境变量 `NO_COLOR=1`。

## 显示和复制设置指南

指南会按步骤显示可以直接粘贴到对应终端中运行的脚本。按 `g` 选择连接目标和密钥后，会打开一个表单，用于确认或更改本地和连接目标各自的操作系统（linux / macos / windows）。默认值为运行应用的操作系统和已保存的连接目标操作系统。对于 Windows 连接目标，还需指定账户类型。按 Ctrl+S 生成指南，用 ← / → 或 `b` / `n` 选择步骤，然后按 `y` 只复制该步骤的脚本。说明文字和面向其他终端的脚本不包含在复制内容中。CLI 的 `hosts guide` 会显示所有步骤。

1. **连接目标的终端**：运行与所选连接目标操作系统相应的公钥部署脚本。Linux/macOS 使用登录用户的 POSIX shell，Windows 标准账户使用本人的 PowerShell，Windows 管理员账户使用以管理员身份打开的 PowerShell。脚本会保留现有公钥并追加，同时设置所需权限。如果已存在相同的公钥，则不会重复追加。
   - **主机密钥尚未固定时**：接着会显示在连接目标上显示主机公钥（Windows 上使用以管理员身份打开的 PowerShell），并在本地终端中将其粘贴到 `ssh-keyflow hosts pin` 的步骤。在 TUI 中选择连接目标后按 `t`，即可在原生终端中完成同样的粘贴和确认。固定后重新生成指南，下面的 SSH config 中会增加用于固定的行。这些内容仅在本地操作系统与运行应用的系统相同时显示。
2. **本地终端**：对于带私钥的密钥，运行面向所选本地操作系统的 SSH config 追加脚本。Windows 使用 PowerShell，Linux/macOS 使用 POSIX shell。如果选择了与运行应用的系统不同的操作系统，请指定从该终端看到的对应私钥路径。脚本会保留现有内容；如果已存在相同的显式别名，则会停止。Include、通配符、Match 和优先级请在运行前自行确认。
3. **本地终端（带口令的密钥）**：这是让 ssh-agent 自动启动的步骤。根据私钥的格式头判断是否带口令，对于带口令或无法判断的密钥会显示此步骤（无法判断时会注明）。SSH config 中会加入 `AddKeysToAgent yes`，在首次连接时将密钥加载到 agent，并保留到 agent 停止为止。Windows 在管理员 PowerShell 中将 `ssh-agent` 服务设置为自动启动。macOS 会确认 launchd 的 agent，并通过 `UseKeychain yes` 将口令保存到钥匙串。Linux 只确认能否连到 agent，并引导你从 keyring、systemd 用户服务或 shell 配置文件中选择设置方式。
4. **本地终端**：运行最后一步的 `ssh 別名`（`別名` 处为连接目标的别名）。

对于仅有公钥的密钥，指南会将公钥文件用作 `IdentityFile`，并提示需要将对应的私钥加载到 SSH 代理中。此时不显示 ssh-agent 步骤。指南中还包含手动移除说明。请事先确保 SSH 服务器和网络可用；对于自定义配置的连接目标，请确认实际的 `AuthorizedKeysFile` / `Match`。Windows 的追加脚本处理 UTF-8 编码的现有文件，遇到 UTF-16 等编码时不会改写，而是停止。

## 固定主机密钥

在连接目标的列表或详情中按 `t`，会切换到原生终端，并显示需要在连接目标上运行的命令。粘贴在连接目标自身终端中输出的主机公钥，在空行处按 Enter，确认显示的指纹后输入 `yes`。如果已固定了不同的密钥，会显示新旧指纹和警告。只有在连接目标自身上确认主机密钥确实已更改时，才输入 `yes`。`T` 会在确认后解除固定。详情界面显示 `Host keys: pinned (N)` / `not pinned` / `unknown`。`unknown` 表示无法读取固定文件，应用不会自动修复。

密钥与连接目标的关联只是本地备忘。保存、显示或复制都不代表注册或连接成功，也没有在手动操作后记录成功的功能。应用不运行脚本，也不执行 SSH 连接、注册或移除，不会直接编辑 SSH 设置或 Include。只有当用户运行复制的脚本时，才会追加公钥或本地 config。删除密钥文件需要用户确认必要性后手动进行。
