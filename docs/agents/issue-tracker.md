# Issue tracker: Local Markdown

- 機能ごとのディレクトリ：.scratch/<feature-slug>/
- 仕様書：spec.md
- チケット：issues/<NN>-<slug>.md（01から連番、1件1ファイル）
- 状態：各チケット冒頭の Status: に記録する。
- 状態の語彙：triage-labels.md を参照する。
- 依存関係：Blocked by: にブロッカーのチケット番号を記録する。
- コメント：各チケット末尾の Comments 見出し以下に追記する。
- 「課題管理へ公開」は、上記の場所へのファイル作成を意味する。
