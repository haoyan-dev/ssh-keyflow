# トラブルシューティング

[简体中文](../zh-CN/guides/troubleshooting.md) · [English](../en/guides/troubleshooting.md) · 日本語

[ドキュメント一覧](../README.md)

## コマンドが見つからない

新しい端末を開いて再試行します。PATH追加を断った場合は、インストーラーが表示した本体のフルパスを使ってください。Windows PowerShellとPowerShell 7ではプロファイルが異なります。[配置先とPATHの説明](installation.md)を参照してください。

## TUIが開かない・変更操作が拒否される

TUIには入力・出力とも対話端末が必要です。変更操作も実端末の確認を要求します。パイプへ流した `yes` で確認を代替せず、対話端末で実行してください。非端末で引数なし起動するとヘルプを表示します。一覧・公開鍵・ガイドの表示はリダイレクトできます。

## 公開鍵やガイドをコピーできない

TUIのコピーにはOSC52対応端末が必要です。対応しない場合は次の出力をエディターやOSのクリップボードへ取り込んでください。名前は自分の管理名・別名または固定IDへ置き換えます。

```sh
ssh-keyflow keys public --key laptop
ssh-keyflow hosts guide --host my-server --key laptop
```

公開鍵は1行を維持し、表示上の折り返しを改行として貼り付けないでください。ガイドは端末ごとのステップを分けて実行します。

## 鍵作成が中断した

```sh
ssh-keyflow keys list
ssh-keyflow resume --id creation-example
```

`creation-example` は一覧の未完了作成IDへ置き換えます。再開は同じID・保存パスを使います。部分ファイルを削除して作り直したり、別の鍵を同じ場所へ上書きしたりせず、指紋・ファイルの不一致があれば内容を確認してください。

## 鍵・状態・ロックのエラーが出る

対象ファイルの移動・置換、権限、別プロセスの実行を確認します。アプリは不明なロックや不正な状態を自動修復しません。別の操作が進行中なら終了を待ちます。ロックや状態を無条件に削除せず、アプリを止めて[データと復旧](data-and-recovery.md)を確認してください。未完了の旧鍵削除がある鍵は手動確認が必要です。

## ガイドを実行してもSSH接続できない

関連付け・表示・コピーは接続成功の証拠ではありません。ガイドが指定するOS、Windowsアカウント種別、貼り付け先、秘密鍵パスを確認します。接続先のSSHサーバー、ネットワーク、実際の `AuthorizedKeysFile` / `Match`、既存configの優先順位も確認してください。これらはアプリが自動検証する範囲に含まれません。

パスフレーズを繰り返し要求される場合は、ガイドのssh-agentステップを確認します。agentが終了すると読み込んだ鍵は保持されません。macOSのキーチェーン、Linuxのagent管理、WindowsサービスはOSごとの手順に従います。

## Host key verification failed と表示される

ホスト鍵を固定した接続先では、固定した鍵以外を拒否します。接続先を再インストールしたりホスト鍵を更新したりした場合は、接続先自身の端末で新しいホスト公開鍵を確認してから、実端末で `ssh-keyflow hosts pin --host <ID> --replace` を実行してください。理由が分からない変更は攻撃の可能性があるため、置き換えないでください。固定を解除した場合は、SSH configに加えた `HostKeyAlias`・`UserKnownHostsFile`・`StrictHostKeyChecking` の3行も削除します。`hosts list` で `unknown` と表示される場合は `~/.ssh/ssh-keyflow/known_hosts` を確認します。アプリは不正な固定ファイルを書き換えません。

公開鍵のみの鍵で接続できない場合は、対応する秘密鍵がエージェントに読み込まれているか確認します。Windowsで `UNPROTECTED PRIVATE KEY FILE` の警告が公開鍵ファイル（`.pub`）を示す場合も、エージェントに鍵がないことを示します。OpenSSHがエージェントで鍵を見つけられず、公開鍵ファイルを秘密鍵として読もうとしたためです。公開鍵ファイルの権限は変更せず、エージェントに秘密鍵を読み込んでください。警告が秘密鍵ファイルを示す場合は、ほかのユーザーが読めないようにそのファイルの権限を制限します。

## インストーラーが更新・削除を拒否する

所有記録のない既存ファイルや、配置後に変更されたファイルは上書きしません。バイナリを手動で差し替えた場合も所有ハッシュが一致しなくなります。[旧インストーラーと手動保守](installation.md#v010のインストーラー利用者)を確認し、他のファイルやプロファイル全体を削除しないでください。

## 報告に含める情報

[コントリビューション](../../CONTRIBUTING.md)の報告手順に従い、版、OS / CPU、端末、実行コマンド、期待結果、実際の診断、最小の再現手順を記録します。秘密鍵・パスフレーズ・認証トークンは含めず、ホスト名・ユーザー名・パス・状態の内容も公開前に確認してください。
