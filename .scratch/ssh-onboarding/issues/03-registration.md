# 03: 自動登録・指定鍵の接続確認・SSH別名設定

Status: ready-for-agent
Blocked by: 02

## What to build

自動登録・指定鍵の接続確認・SSH別名設定を対話CLIから完了できる。spec.md、requirements.md、plan.md の該当要件を満たす。

## Acceptance criteria

- [ ] 既存鍵またはパスワードで新規ログインし、自分の公開鍵を重複なく登録する
- [ ] OSと標準登録先の確認、Windows共有管理者ファイルの影響確認を行う
- [ ] ホスト鍵検証を保持し、指定鍵だけで接続結果を確認する
- [ ] 結果不明を再確認し、登録状態と接続結果を分けて記録する
- [ ] 別名衝突と管理対象外設定を保護し、Includeの差分・バックアップ・承認または手動案内が機能する
- [ ] CLI境界で登録と設定保護をTDDで検証する
