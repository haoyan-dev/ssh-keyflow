# 04: 別認証確認・公開鍵登録解除・ローカル鍵削除

Status: ready-for-agent
Blocked by: 03

## What to build

別認証確認・公開鍵登録解除・ローカル鍵削除を対話CLIから完了できる。spec.md、requirements.md、plan.md の該当要件を満たす。

## Acceptance criteria

- [ ] 対象鍵と多重化接続を除いた別認証による新規ログインを確認する
- [ ] 最終承認の後に指定した公開鍵だけを解除し、他の鍵とコメントを保持する
- [ ] 別認証不能や到達不能では自動解除を止め、手動解除手順を示し鍵を残す
- [ ] 登録が残る間や要確認状態ではローカル鍵削除を止める
- [ ] 解除済み再実行、結果不明とローカル削除をCLI境界でTDD検証する
