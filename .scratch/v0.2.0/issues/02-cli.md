# 02: CobraによるCLI

Status: ready-for-agent
Blocked by: 01

## What to build

[spec.md](../spec.md) の操作をCobraのサブコマンドで提供する。独自のコマンドパーサーやヘルプ生成を実装しない。

## Acceptance criteria

- [ ] specのコマンドと既存主要操作を提供し、各フラグ、対象の指定方法、承認、再開方法をヘルプと契約へ記録する。
- [ ] 不足・不正・曖昧な入力を副作用前に検出し、使用法エラー2を返す。
- [ ] 一覧のJSON出力と診断を分離し、秘密値を出力しない。
- [ ] 変更の確認とOpenSSHの認証は端末で扱い、端末なしでは必要な操作を副作用前に拒否する。
- [ ] --help/--versionは初期化不要。一覧はSSH依存や書き込みを要求しない。非端末で引数なしの場合はヘルプを表示する。
- [ ] 登録解除とローカル鍵の削除を分け、既存の安全条件を確認省略フラグで回避しない。
- [ ] 共通処理を使い、一時home・外部コマンド境界による主要操作、JSON、終了コードのテストが通る。
