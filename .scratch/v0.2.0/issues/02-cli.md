# 02: CobraによるCLI

Status: ready-for-agent
Resolution: completed
Blocked by: 01

## What to build

[spec.md](../spec.md) の操作をCobraのサブコマンドで提供する。独自のコマンドパーサーやヘルプ生成を実装しない。

## Acceptance criteria

- [x] specのコマンドと既存主要操作を提供し、各フラグ、対象の指定方法、承認、再開方法をヘルプと契約へ記録する。
- [x] 不足・不正・曖昧な入力を副作用前に検出し、使用法エラー2を返す。
- [x] 一覧のJSON出力と診断を分離し、秘密値を出力しない。
- [x] 変更の確認とOpenSSHの認証は端末で扱い、端末なしでは必要な操作を副作用前に拒否する。
- [x] --help/--versionは初期化不要。一覧はSSH依存や書き込みを要求しない。非端末で引数なしの場合はヘルプを表示する。
- [x] 登録解除とローカル鍵の削除を分け、既存の安全条件を確認省略フラグで回避しない。
- [x] 共通処理を使い、一時home・外部コマンド境界による主要操作、JSON、終了コードのテストが通る。

## Resolution

completed (2026-11-06): Cobra v1.10.2による直接指定CLIと公開入口`cli.Run`を実装。端末判定に既存ライブラリ`github.com/charmbracelet/x/term` v0.2.2を使用し、独自パーサーや確認省略フラグを追加していない。コマンド、フラグ、JSON形式と終了コードはapplication-contractへ記録した。

- TDD: ヘルプ・非端末起動、一覧JSON、直接操作の入力検証と端末拒否、バージョンと終了コードの各スライスで未実装による失敗を確認して実装した。
- 共通処理から曖昧・不明な対象を`ErrInvalidInput`として識別できるようにし、対象不在で保存先を作る失敗をテストして修正。操作ロック内でも対象を再確認する。
- 主な業務処理は既存app境界で検証し、CLI境界では引数・出力・終了コード・非端末拒否を確認する。秘密値や既存ユーザーのSSHデータは使っていない。
- `go test ./...`: PASS（最終app 48.983秒、cli 1.566秒、sshはキャッシュ成功）。`go vet ./...`: PASS。
- CGO無効でWindows/Linux/macOS × amd64/arm64の6対象の実CLIビルド成功。Windows amd64の実行ファイルを隔離ホームで実行し、version/help/引数なし/一覧JSON/変更拒否・使用法エラーとSSH保存先の無変更を確認した。
- TUI起動は`Options.RunTUI func(context.Context, app.Options) error`へ接続する。チケット03が実際のTUIを提供してmainへ接続する。実端末での認証・TUI復元は後続検証であり、このチケットの非端末スモークとは区別する。
