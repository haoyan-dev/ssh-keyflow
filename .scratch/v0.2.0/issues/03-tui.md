# 03: Bubble Teaによる一覧中心のTUI

Status: ready-for-agent
Blocked by: 01, 02

## What to build

[spec.md](../spec.md) に従い、Bubble Tea・Bubbles・Lip Glossを利用して番号選択メニューを置き換える。02の起動分岐へTUIを接続する。

## Acceptance criteria

- [ ] 端末での引数なし起動と明示的なtui起動で、接続先・鍵・登録履歴の一覧を表示する。
- [ ] 一覧・詳細から既存主要操作、作成途中や結果不明の処理の再開、手動手順へ進める。
- [ ] 入力・選択・ヘルプには既存部品を使い、長い番号選択の質問列を廃止する。
- [ ] 変更対象と内容を実行前に確認でき、戻る・キャンセルで変更しない。
- [ ] OpenSSHへ元の端末を渡し、成功・失敗・中断後に端末と表示を復元する。秘密値をTUI側で保持しない。
- [ ] リサイズ、狭い端末、キーボード操作と終了を確認する。
- [ ] 共通処理を使い、画面遷移・キャンセルと端末受け渡しの検証を行う。実端末での確認結果と自動テストを区別して記録する。
