# 04: インストーラー廃止とPortable配布への統一

Status: ready-for-agent
Blocked by: 02, 03

## What to build

[spec.md](../spec.md) に従い、現行の梱包処理を修正して6対象のPortableアーカイブを配布する。インストーラー、関連テスト・案内を整理し、CI・リリース契約を更新する。

## Acceptance criteria

- [ ] 6対象アーカイブとSHA256SUMSを生成し、インストーラーを添付しない。必要な依存ライセンス文書を同梱する。
- [ ] manifestは6アーカイブを対象とし、アーカイブの内容・実行権限・チェックサム・バージョン注入をテストする。
- [ ] 展開実行、アプリ終了後の差し替え、手動PATH設定、本体削除をREADMEに記載する。
- [ ] 本体の移動・差し替え・削除で既存の鍵・状態・設定・リモート登録を変更しない。
- [ ] 旧インストーラー利用者向けに、既存PATH・所有記録を自動変更しないことと、手動差し替え後は旧スクリプトによる更新・削除が拒否され得ることを説明する。
- [ ] installer専用テストを整理し、Portableの梱包テスト、Goテスト、6対象クロスビルドへCIを更新する。
- [ ] README、application-contract、verificationとリリース定義を最終実装へ揃え、実機未検証の対象を明記する。
- [ ] このチケットの完了を理由にタグ作成・push・公開を行わない。
